# MivbSync releases

Release builds of MiVB Recording Coverage Sync (`MivbSync.exe`) for ASC Neo.

This repo holds only the published releases. Each release carries `MivbSync.exe`,
`config.example.toml` and `SHA256SUMS.txt`. Installed copies check here at the start of each
nightly sync and update themselves (the `[update]` section in `config.toml`).

Releases are published automatically from the source repository; please do not upload
assets by hand.
